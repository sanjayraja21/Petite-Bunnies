# Petite Bunnies
A modern, responsive, and elegant pet and farm-animal website built with **React, Vite, Tailwind CSS, Framer Motion, and React Router.
Petite Bunnies is designed to showcase healthy bunnies, cheerful chicks, and country hens with an easy-to-use and mobile-friendly interface.

## What It Does
- Helps users explore available bunnies, chicks, and hens.
- Displays animal images, categories, details, and availability.
- Allows users to save favorites and manage selected animals.
- Provides direct phone and email contact options.
- Gives customers an easy and responsive way to explore Petite Bunnies online.

## Features
- Browse bunnies, baby chicks, and country hens.
- View animal details, availability and contact details.
- Explore animals through categories and easy navigation.
- Fully responsive design for desktop, tablet, and mobile.
- Deployed on Render with automatic GitHub deployment.

# Design

Petite Bunnies uses a soft, elegant, and friendly design style.
The UI includes:
-  Soft pink colors
-  Natural green accents
-  Clean white cards
-  Rounded UI elements
-  Smooth animations
-  Animal-focused images
-  Glass-style UI elements
-  Responsive layouts
